# Численная модель

## Уравнения

Решаются осреднённые уравнения несжимаемой жидкости без объёмных сил:

```text
div(U) = 0
dU/dt + U·grad(U) = -grad(p*) + div[(nu + nu_t)(grad(U) + grad(U)^T)]
nu_t = Cmu k² / epsilon
p* = p_static/rho + 2 k/3

dk/dt + div(U k) = div[(nu + nu_t/sigma_k) grad(k)] + Pk - epsilon
depsilon/dt + div(U epsilon)
  = div[(nu + nu_t/sigma_epsilon) grad(epsilon)]
    + C1 epsilon/k Pk - C2 epsilon²/k
Pk = nu_t [2 ux² + 2 vy² + (uy + vx)²]
```

Константы: Cmu = 0.09, C1 = 1.44, C2 = 1.92, sigma_k = 1.0,
sigma_epsilon = 1.3. Вход: k = 1.5 (U I)², I = 0.05;
epsilon = Cmu^(3/4) k^(3/2)/(0.07 H).

Сохранённое давление — **статическое**: rho·(p* − 2k/3 + 2 mean(k_out)/3).
Точка отсчёта выбрана по среднему k на выходе; механическое давление на
выходной грани равно нулю. Величина в GUI «Δp вход–выход» — разность средних
статических давлений в первом и последнем рядах ячеек, а не на внешних гранях.

## Нестационарный режим: сетка и шаг

Давление, k и epsilon хранятся в центрах, u и v — на соответствующих гранях
(MAC). Прямоугольные твёрдые ячейки исключены из матрицы давления.
Между жидкостью и твёрдым телом нормальная скорость точно равна нулю.

Перенос импульса — явная противопоточная схема первого порядка на смещённых
контрольных объёмах. Вязкие потоки используют среднюю вязкость на гранях;
добавлены члены градиента турбулентной вязкости от транспонированного тензора
градиента скорости. k и epsilon переносятся консервативными потоками тех же
скоростей, что обеспечивают неразрывность. Разрушение k и epsilon учитывается
полунеявно, что помогает сохранять положительность.

Прогноз скорости затем проецируется на бездивергентное поле:

```text
laplacian(p*) = div(U_predictor)/dt
U_new = U_predictor - dt grad(p*)
```

На выходе p* = 0 на грани (расстояние до центра dx/2); на входе и стенках
нулевой нормальный градиент давления. Открытый верх/низ также задаёт p* = 0
на грани с расстоянием dy/2; проекция корректирует нормальную скорость на этих
гранях. Из стеночных масок открытые части исключаются. Для обратного потока
через открытую границу k/epsilon берутся из входных значений.

В прямоугольнике без препятствий отрицательный лапласиан диагонализуется
ортонормированными косинусными/синусными преобразованиями SciPy FFT: по x —
DCT-IV (Neumann/Dirichlet), по y — DCT-II, DCT-IV, DST-IV или DST-II
для сочетаний стенка/стенка, стенка/открытая, открытая/стенка и открытая/открытая.
Это точное решение дискретной системы с линейной памятью, без LU-факторизации.

При препятствиях до 20000 жидких ячеек используется постоянная разреженная
матрица с факторизацией SciPy/SuperLU. Более крупные области используют CG
с rtol = 1e−10 и atol = 1e−12, до 1000 итераций. Предобусловливатель —
ограничение обратного прямоугольного лапласиана на жидкие ячейки. При отсутствии
сходимости расчёт сообщает ошибку, а не использует непроверенное давление.
Конструкция матрицы использует массивы NumPy вместо списков отдельных элементов.
Начальная скорость также
проецируется; начальное давление записывается нулевым, до первого физического шага.

Шаг автоматически выбирается как минимум ограничений адвекции с CFL = 0.35,
диффузии `0.2 / [max(nu_eff)(1/dx² + 1/dy²)]` и времени до следующего кадра.
Проверяется конечность решения. Численные ограничения: nu_t ≤ 0.1 U_in H,
Pk ≤ 10 epsilon (кроме предписанных пристеночных значений), k и epsilon ≥ 1e−10
в жидкости. Это явно заданные стабилизаторы модели; универсальной оценки их
ошибки нет. Результаты при изменении режима требуют независимой проверки.

## Стационарный SIMPLE

Здесь нет интегрирования до заданной секунды и нет ограничения CFL.
На каждой внешней итерации:

1. Вычисляются nu_t, конвективные коэффициенты и источники по предыдущему состоянию.
2. Для u/v собирается разреженный оператор первого порядка по потоку с неявной
   диффузией переменной вязкости. Отрицательная часть стеночного источника
   линеаризуется неявно; оставшиеся поперечные добавки тензора напряжений лагируются.
3. Уравнения импульса решаются с релаксацией alpha_U = 0.65. Если a_P —
   диагональ нерелаксированного уравнения, d = alpha_U/a_P на внутренних гранях.
4. По локальным d собирается уравнение коррекции давления:
   `-div(d grad(p')) = -div(U*)`. Используется фактическая диагональ импульса,
   а не постоянный шаг проекции. Скорости корректируются как `U = U* - d grad(p')`,
   давление — `p* = p*_old + 0.25 p'`. На открытых гранях p' = 0 с половинным
   расстоянием до центра. На входе скорость фиксирована, на стенке нормальная
   скорость нулевая. Прогноз нормальной скорости на открытой грани копирует
   соседнее внутреннее значение; коррекция давления затем обеспечивает расход.
5. С текущими скоростями решаются неявные консервативные уравнения k/epsilon,
   включая диффузию и линеаризованные отрицательные источники; alpha_k/epsilon = 0.7.

Для каждой транспортной системы сохраняется невязка **нерелаксированного**
уравнения `||A q - b||₂ / max(||b||₂, characteristic_scale sqrt(N), 1e-14)`.
Характерный масштаб импульса — U_in²/L, скаляров — k_in U_in/L и epsilon_in U_in/L.
Неразрывность контролируется отдельно как `max|div U| L/U_in` после коррекции.
Требуются все пять невязок ниже заданного порога три итерации подряд, минимум
10 итераций. Максимальное число итераций — страховочный предел, не критерий успеха.
История и признак `converged` записываются в результат.

Линейные системы до 100 неизвестных решаются напрямую. До 20000 — через
кешируемый LU-предобусловливатель, более крупные — через AMG PyAMG Ruge–Stuben.
Иерархия или факторизация обновляется каждые 20 вызовов соответствующего поля.
При неуспехе итерационного решения предобусловливатель обновляется и выполняется
одна повторная попытка; дальнейший неуспех останавливает расчёт с ошибкой.
Импульс и скаляры используют BiCGSTAB с rtol = 1e−8, давление — CG с rtol = 1e−9,
общие atol = 1e−11 и лимит 400 линейных итераций. Кешируемый обратный LU
симметричной положительно определённой системы давления также является SPD;
AMG использует симметричное сглаживание. Диагональ и связи давления пересобираются
на каждой внешней итерации; повторно используется только предобусловливатель.

При включённом грубом старте разрешение уменьшается пропорционально до примерно
96×32 или меньше. Грубое решение (до 200 итераций, порог не строже 5e−4)
интерполируется на расположения соответствующих неизвестных целевой MAC-сетки.
Начальная скорость проецируется для восстановления неразрывности, затем все
невязки проверяются заново на целевой сетке. Даже несошедшееся грубое решение
может служить начальным приближением; оно не устанавливает `converged` целевой задачи.

Numba компилирует транспортные циклы и сборку разреженных операторов, не меняя
уравнения и не включая `fastmath`. Первая компиляция требует дополнительного времени,
последующие процессы используют файловый кеш. Внутри расчёта BLAS ограничен
одним потоком через threadpoolctl; исходные настройки восстанавливаются после выхода.
Это не многопоточный или GPU-решатель и не обещание скорости ANSYS.

Результат SIMPLE содержит два одинаковых итоговых поля для плеера.
`Result.time` в этом режиме — время анимации, а не физическая история решения.

## Стенка

Для скорости по касательной в прилегающей ячейке нелинейно решается
гладкостенная логарифмическая зависимость:

```text
U_t/u_tau = ln(9.8 y u_tau/nu)/0.41
```

В вязкой ветви используется u_tau = sqrt(nu |U_t| / y), переключение при
y⁺ = 11.06. Потеря импульса от напряжения стенки u_tau² задаётся в примыкающем
контрольном объёме; на нормальную скорость это не влияет. В стеночных ячейках
задаются k = u_tau²/sqrt(Cmu), epsilon = u_tau³/(0.41 y), Pk = epsilon.
В угловых ячейках значения усредняются по соседним стенкам.
Это простая равновесная пристеночная модель, ограниченно применимая к отрыву.

## Проверки

- Проекция случайного поля с препятствием: малая дивергенция и одинаковый расход.
- Изготовленное дискретное поле давления: восстановление исходного потенциала
  и удаление градиентной части скорости.
- Диффузия: сохранение интеграла и диссипация энергии скаляра.
- Прямой канал: положительность k/epsilon, изменение между последними кадрами,
  сравнение давления с зависимостью Дина на двух сетках в тестах и трёх в отчёте.
- Ступенька: наличие обратной скорости ниже основной струи, баланс расхода,
  отсутствие обратного потока на выходе, сохранение/чтение всех полей.
- GUI offscreen: запуск рабочего процесса, результат, воспроизведение, перемотка,
  геометрический масштаб изображения и переключение отображения.
- Все шесть геометрий и четыре сочетания верх/низ: проекция случайного поля,
  реальный расчёт, баланс суммарного расхода через все открытые границы.
- CG сравнивается с прямой факторизацией на одной задаче для каждого сочетания границ.
- Размер 1024 по каждой оси проверен отдельными тестами; полный 1024² и геометрии
  1024×256 проверяются настоящим коротким расчётом через `benchmark --extended`.
- Старые NPZ-файлы без настроек границ читаются с двумя стенками по умолчанию.
- Неявные операторы сверяются с дискретным консервативным балансом и
  исходными явными операторами; совпадение проверяется до округления double.
- SIMPLE: сходимость канала/сужения, совпадение конечного поля с нестационарным
  решением, открытые границы, отмена и честный признак достижения лимита.
- Крупная изготовленная линейная система проверяет AMG; GUI отдельно проверяет
  стационарный процесс и показ несходимости вместо ложного успеха.
